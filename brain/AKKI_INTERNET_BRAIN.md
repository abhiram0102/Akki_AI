## How It Learns Without Instructions

### Stage 1 — Raw Exposure

It receives bytes from the internet.
It knows nothing about what they mean.
It just stores them. All of them.

### Stage 2 — Pattern Emergence

From billions of bytes — patterns appear on their own.
Certain sequences repeat. Certain structures are consistent.
The brain notices these without being told what to look for.

This is how it discovers:
- What a word is (repeated sequences separated by spaces)
- What a sentence is (sequences ending in specific characters)
- What a link is (sequences that when used as addresses return new responses)
- What language is (recurring patterns of sounds and symbols)

Nobody defined these. They emerged from the data.

### Stage 3 — Connection Building

Once it knows what words are —
It notices which words appear together consistently.
Those co-occurrences ARE connections.
Connections ARE knowledge.

### Stage 4 — Direction Learning

From the position of words in sentences —
It learns which concepts cause which other concepts.
Earlier in sentences = cause. Later = effect.
No grammar rules given. Position statistics reveal it.

### Stage 5 — Knowing

After enough exposure — it stops being random.
It knows which connections are real.
It knows which directions are true.
It starts moving through the internet with purpose — not instruction.

This is the transition from exploration to intelligence.

## Where the Brain Lives

### Current (temporary)

```
brain/knowledge.pkl  ←  flat file on disk
```

Works for small brains. Breaks at scale.

### Real Architecture

```
Layer 1 — RAM
  Everything currently active loaded in memory.
  Instant access. Zero latency.

Layer 2 — Graph Database (Neo4j)
  Every concept = node.
  Every connection = edge with strength and direction.
  Permanent. Structured. Traversable in milliseconds.

Layer 3 — Vector Store (ChromaDB / pgvector)
  Every concept stored as a mathematical representation.
  Query by meaning — not exact word.
  "Find everything similar to consciousness"

Layer 4 — Object Storage
  Raw text the brain has read.
  Every page. Every sentence. Compressed. Cheap.
  Reference if needed.

Layer 5 — Distributed (when massive)
  Brain spreads across multiple machines.
  Each machine holds part of the graph.
  Together they are one brain.
```
